# Release suite in CI

Run the release suite's full post-review pass (the full candidate suite, the interop suite, the hello-world base test, the launch function comparison, the `Invoke-BaselineSuite.ps1` refresh and the baseline comparison of `Invoke-PostReviewChecks.ps1`) as a CI job on the reviewed commit once the project lives in GitHub repositories, so a release no longer waits at the terminal for it and the publication procedure in `AGENTS.md` can cite a green run for the reviewed commit instead of local `suite-*.txt` files. Depends on the move to repositories, the Repository home slice of [Composable AI bootstrap builder](https://github.com/astenlund/Pluri-Bot/blob/main/.nightshift/features/composable-bootstrap-builder.md). A GitHub-hosted runner, or a self-hosted one running as a service, has no visible desktop, so the off-screen machinery (the private desktop and the console host switch of `Invoke-SuiteOffscreen.ps1`) may become unnecessary there. Open questions: since that slice splits the project into a builder repository and a DLSS repository built on its base file, which repository's CI runs which part of the pass; a GitHub-hosted Windows runner or a self-hosted one on the author's machine (a standard GitHub-hosted runner has no NVIDIA GPU, and no hosted runner has this machine's displays or state, so the cases marked `# live-input` would need fixtures or stay local, while a self-hosted runner keeps them meaningful but uses the author's machine again); whether any case reads state outside `test-runs\` (the canonical AppData copy, the engine store, a host CLI), which needs a sweep before a clean runner is trusted; how the baseline's carry rules and `candidate-results.json` read the previous release's frozen candidate and results from the repositories rather than sibling release folders; the cost of Windows runner minutes for a run that takes over an hour locally (about 74 minutes for v67's candidate suite; hosted timing unmeasured); and how install and publication are gated on the run's result for the exact reviewed bytes. User idea, 2026-11-20.
