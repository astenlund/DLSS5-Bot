# DLSS5-Bot

DLSS5-Bot adds and maintains NVIDIA DLSS 5 in PC games. It is one self-contained Windows `.cmd` file: placed in a game folder and launched, it starts Claude Code or Codex CLI with a prompt for safe, verified game-session work, and keeps notes per game and per machine. It is the DLSS 5 mission for the [Pluri-Bot](https://github.com/astenlund/Pluri-Bot) engine and began as DLSS5-ADDER, published from a gist.

The published package today is legacy v67, `DLSS5-ADDER.cmd`, still served from its gist. From v1-1 the package is released here on GitHub Releases as `DLSS5-Bot.cmd`, numbered as a pair of engine and mission versions, and copies update from this repository's latest release.

This repository is never renamed, transferred or deleted: from v1-1 every copy reads its releases and refuses redirects.

See `AGENTS.md` for the layout and the working rules.
